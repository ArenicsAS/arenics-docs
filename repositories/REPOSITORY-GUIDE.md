# Arenics Repository Guide

Denne oversikten skal fylles med faktiske repository-navn og eierskap etter hvert som ArenicsAS-repositoriene etableres/kartlegges.

## Systemområder

- CubeStudio
- HockeyScores
- HandballScores
- Arena Signage / Digital Signage
- MoveDisplay
- WayGuide
- Arenics Portal
- Arenics Support
- GBF / Havnekontroll
- API-er, tjenester og verktøy

> Ikke opprett repository-navn fra antakelser. Registrer det faktiske GitHub-repositoryet når det er bekreftet.
