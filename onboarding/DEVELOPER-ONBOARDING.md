# Arenics Developer Onboarding

Arenics består av produksjonssystemer med forskjellig alder og teknologistack.

Du vil blant annet møte C#, .NET Framework 4.8, .NET 8, WPF, ASP.NET Web Forms, ASP.NET Core, Razor, SQL Server, HTML/CSS/JavaScript, IIS og Windows-runtime.

## Arbeidsregel

Ikke anta at eldre kode bare skal skrives om. Finn først domenekunnskapen systemet representerer.

## Git

- Branch per avgrenset endring.
- Pull Request før større endringer.
- Beskriv hva, hvorfor og konsekvens.
- Ikke bland opprydding og funksjonelle endringer unødvendig.
- Portvik/Foundation-endringer håndteres i riktig Portvik-repository.
